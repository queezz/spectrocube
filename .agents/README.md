# `.agents/`

Operational memory for SpectroCube assisted development.

| File | Tense | Purpose |
|---|---|---|
| `rules.md` | always | Neutral format, preservation, and release invariants |
| `directions.md` | future | Open work only |
| `CHANGELOG.md` | past, shipped | Assisted-development milestones |
| `commit-culture.md` | always | Commit, version, and gate contract |
| `handoff-template.md` | always | Copyable evidence structure |
| `logs/YYYY-MM-DD-<kebab>.md` | past, session | Detailed release handoffs |

Read `../AGENTS.md` first, then this file, `rules.md`, the newest relevant
log, `commit-culture.md`, and `directions.md`. Product authority remains
`../SPEC.md`, the public documentation, source, and tests.

Keep the three memory tiers separate: directions are open work, CHANGELOG is
shipped history, and logs retain exact evidence and decisions.
